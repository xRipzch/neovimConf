# customNvim

A small personal Neovim config (0.12+), built from
[kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim). It uses the built-in
`vim.pack` plugin manager. Leader = `<Space>`.

`~/.config/nvim` is a symlink to this folder. Open it with `nvim .` or `v` (fish function).

## Layout

```
init.lua                 entry point: requires everything below, in order
lua/config/options.lua   editor settings
lua/config/keymaps.lua   keymaps that need no plugin (splits, ...)
lua/config/autocmds.lua  small automatic behaviours
lua/config/pack.lua      vim.pack helpers + plugin build hooks
lua/config/theme.lua     theme persistence + transparency
lua/config/health.lua    :checkhealth config
lua/plugins/*.lua        one file per feature (installs + configures its plugins)
tests/smoke.lua          automated checks (see "Tests")
nvim-pack-lock.json      exact plugin versions (generated by vim.pack)
```

### Built-in keys worth knowing (not remapped)

| Key | Action |
|---|---|
| `K` | Hover docs |
| `grn` / `gra` | Rename / code action |
| `grr` / `gri` / `grt` | References / implementation / type definition |
| `gO` | Symbols in this file |
| `[d` / `]d` | Previous / next diagnostic (opens its message) |
| `<C-w>d` | Diagnostic under the cursor in a popup |
| `<C-s>` (insert) | Signature help |
| `gc{motion}` / `gcc` | Toggle comment (also `gc` in visual mode) |
| `<C-o>` / `<C-i>` | Jump back / forward (e.g. after `grd`) |

**In the explorer:** `<CR>` open, `a` new file or folder (end the name with `/`
for a folder; new files open right away), `d` delete, `r` rename, `c` copy,
`m` move, `H` show hidden files, `/` filter, `?` all keys. `<C-l>` / `<C-h>`
move between the explorer and your file.

**New files, other ways:** `:e path/new.go` and then `:w`, or in an unnamed
buffer `:w path/new.go`. A plain `:w` fails there because the buffer has no name yet.

**In completion:** `<C-n>`/`<C-p>` move, `<C-y>` accept, `<C-e>` close,
`<C-space>` open menu / docs.

**In Telescope:** type to filter, `<CR>` open, `<C-v>`/`<C-x>` open in a vertical /
horizontal split, `<Esc>` close.

## Extending it

### Add a plugin

1. Create `lua/plugins/<feature>.lua`:
   ```lua
   local pack = require 'config.pack'
   pack.add { pack.gh 'owner/repo' }   -- installed on next start
   require('repo-module').setup {}
   ```
2. Add `require 'plugins.<feature>'` to `init.lua`.
3. Restart Neovim (`:restart`).

To remove a plugin: delete its file and its `require` line, restart, then run
`:lua vim.pack.del({ 'repo' })`. To update plugins: `:lua vim.pack.update()`,
review the list, then `:write` to apply.

### Add a language server

In `lua/plugins/lsp.lua`:
1. Add the server to `SERVERS` using its lspconfig name, with `{}` for the
   defaults, e.g. `rust_analyzer = {}`. The names are listed in `:help lspconfig-all`.
2. Add its Mason package to `MASON_PACKAGES`, e.g. `'rust-analyzer'`. The names
   are shown in `:Mason`.
3. Optional: add a formatter in `plugins/format.lua` (`formatters_by_ft`), a
   linter in `plugins/lint.lua` (`LINTERS_BY_FT`), and the treesitter parser in
   `plugins/treesitter.lua` (`PARSERS`). A missing parser is also installed
   automatically when you open the file.
4. Restart, then check `:checkhealth vim.lsp`.

### Add a keybinding

```lua
vim.keymap.set('n', '<leader>fs', function() require('telescope.builtin').grep_string() end,
  { desc = 'Find word under cursor' })
```

- Plugin keys go in that plugin's file. Plain editor keys go in `config/keymaps.lua`.
- Always give a `desc`: it's what which-key and `<leader>?` show.
- For a new group, add `{ '<leader>x', group = 'name' }` to `spec` in
  `plugins/which-key.lua`.
- Check that a key is free first: `:verbose nmap <leader>fs`.
